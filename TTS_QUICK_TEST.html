🔊 Text-to-Speech Coverage Test Tool

This tool helps you verify that every word on your website can be selected and read by the TTS feature.

📌 Method 1: Bookmarklet (Easiest)

Step 1: Drag this button to your bookmarks bar ⬇️
📊 Test TTS Coverage
Step 2: Navigate to your website
Step 3: Click the bookmarklet in your bookmarks bar
Step 4: Check the results!
  • 🟢 Green outline = Text is selectable (TTS will work)
  • 🔴 Red outline = Text is NOT selectable (needs fixing)

💻 Method 2: Console Script

Open your website, press F12 to open console, paste this code:

// TTS Coverage Checker function checkTTSCoverage() { console.clear(); console.log('🔍 Checking TTS coverage...\n'); let selectable = 0; let notSelectable = 0; const problems = []; document.querySelectorAll('*').forEach(el => { // Only check elements with direct text content if (el.textContent && el.children.length === 0 && el.textContent.trim()) { const style = window.getComputedStyle(el); const userSelect = style.userSelect || style.webkitUserSelect || style.MozUserSelect; if (userSelect !== 'none') { selectable++; el.style.outline = '1px solid green'; } else { notSelectable++; el.style.outline = '2px solid red'; problems.push({ text: el.textContent.trim().substring(0, 50), tag: el.tagName, class: el.className }); } } }); const total = selectable + notSelectable; const coverage = total > 0 ? Math.round((selectable / total) * 100) : 0; console.log('📊 RESULTS:'); console.log('✅ Selectable:', selectable); console.log('❌ Not Selectable:', notSelectable); console.log('📈 Coverage:', coverage + '%\n'); if (coverage >= 95) { console.log('🎉 EXCELLENT! Almost all text is selectable!'); } else if (coverage >= 85) { console.log('👍 GOOD! Most text is selectable.'); } else if (coverage >= 70) { console.log('⚠️ FAIR. Some areas need attention.'); } else { console.log('❌ POOR. Many areas need fixing.'); } if (problems.length > 0 && problems.length <= 10) { console.log('\n⚠️ Problem areas:'); problems.forEach((p, i) => { console.log(`${i+1}. <${p.tag}> "${p.text}..." ${p.class ? `class="${p.class}"` : ''}`); }); } else if (problems.length > 10) { console.log(`\n⚠️ Found ${problems.length} problem areas. Check elements with red outlines.`); } console.log('\n💡 Look for:'); console.log(' 🟢 Green outline = Selectable'); console.log(' 🔴 Red outline = NOT selectable'); return { selectable, notSelectable, coverage, problems }; } checkTTSCoverage();

✅ What to Expect

✅ PASS (95%+ coverage)
Almost all text is selectable. Only images/icons are not selectable.
Action: You're good to go! TTS will work great! 🎉
❌ NEEDS WORK (<95% coverage)
Some text cannot be selected.
Action: Look for red outlines and fix those elements. Check TTS_COMPLETE_COVERAGE_GUIDE.md for solutions.

🎯 Quick Manual Test

Try selecting text in these areas on your website:

  • Navigation menu text
  • Page headings
  • Paragraph text
  • Button labels
  • Card titles
  • Card descriptions
  • Table data
  • List items
  • Footer text
  • Link text
  • Form labels
  • Modal content

If you can highlight it (blue background appears), TTS can read it!

🔧 Common Fixes

If you find text that can't be selected, add to your globals.css:

/* Force specific elements to be selectable */ .your-problem-class { -webkit-user-select: text !important; user-select: text !important; }
